# ECM submission checklist

## Passed by the Step 6 build

- [x] Manuscript is framed as a prospective conditional constraint analysis.
- [x] The public `1 TW/year` output wording is never equated to facility load.
- [x] Abstract is at most 250 words.
- [x] One to seven keywords are supplied.
- [x] Five highlights are supplied and each is at most 85 characters.
- [x] All ten prespecified figures and six tables are represented.
- [x] Figure 3 is labelled as a benchmark diagnostic, not independent validation.
- [x] Figure 7 uses accredited-capacity/reserve-margin screening instead of
  unavailable LOLE/EUE.
- [x] Figure 8 is limited to EIA annual-electricity context.
- [x] Every plotted figure has a machine-readable CSV and SHA-256 manifest.
- [x] H1--H4 remain indeterminate.
- [x] Failed, passed, and indeterminate gates remain distinct.
- [x] The public evidence snapshots are frozen; reproduction performs no live
  retrieval.
- [x] Source-available, non-affiliation, no-verified-data, and assumption-boundary
  notices are retained.
- [x] A generative-AI declaration appears immediately before the references.
- [x] The LaTeX manuscript, supplement, and cover letter compile without errors.

## Author-controlled checks before journal upload

- [ ] Confirm the final author spelling, affiliation, postal address, and
  corresponding-author email in the submission system.
- [ ] Supply the accurate funding statement; this repository does not infer it.
- [ ] Confirm the competing-interest wording concerning KNOWDYN ownership of the
  source-available software.
- [ ] Confirm the exact OpenAI Codex model/version from the author’s access record
  and update the AI declaration if Elsevier requires greater specificity.
- [ ] Replace the repository-version language with the final Git commit, release,
  and archival DOI after Step 7 and archival deposition.
- [ ] Recheck the live ECM guide immediately before submission.
- [ ] Run a human reference audit against every primary source and approve every
  interpretation, table, figure, and conclusion.
- [ ] Confirm that all third-party source and figure permissions are satisfied;
  the paper figures themselves are deterministic plots generated by this study.
- [ ] Select the journal's current article type, classifications, and suggested
  reviewers in the submission system.

These administrative confirmations do not change the computational result, but
they are mandatory before journal submission.
